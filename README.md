## flecs_wrapper

A high(ish) wrapper for the Flecs ECS library, primarily for use with my haxe/nim/D experiments

###  Flecs repo :  https://github.com/SanderMertens/flecs

The src/flecs.c and include/flecs.h were pulled directly from the Flecs github repo (v4.0.5): 
- https://github.com/SanderMertens/flecs/blob/master/distr/flecs.h
 - https://github.com/SanderMertens/flecs/blob/master/distr/flecs.c
